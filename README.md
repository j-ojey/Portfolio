# GW. — The Build Lab

Personal portfolio for George Kihoro, built as an interactive developer workspace rather than a static résumé.

## What is inside

- **Build DNA** — an interactive way to explore problem-solving traits.
- **Number Lab** — a five-question mathematical quiz with dynamically generated questions, randomized answers, progressive difficulty, scoring, replay, and a retro lab interface.
- **Workshop** — selected software, sustainability, AI, and civic-technology projects.
- **Developer workstation** — a browser-based terminal with portfolio commands such as `ls`, `tree`, `projects`, `skills`, and `contact`.
- **Collaboration console** — a responsive developer-style contact form that prepares a message in the visitor’s email client.
- **CV downloads** — available from [`assets/George-Wainaina-CV.docx`](assets/George-Wainaina-CV.docx).

## Tech

This is a lightweight static site using:

- HTML
- CSS
- Vanilla JavaScript

## Contact behavior

The contact form does not send data to a server. After browser validation, it creates a `mailto:` link containing the submitted name, email, topic, and message. A default email client must be configured on the visitor’s device for the compose window to open.
